【表 0：文件信息与适用范围】写到 {{OUT_META}}
  列（UTF-8 带 BOM，逗号分隔，含逗号的值用双引号）：field, value, quote, source_file, source_location, note
    quote：支持 value 的原文，照抄，200 字以内；没有原文依据就留空
  field 必须包含下面几行；文件没写的，value 写「不明」，quote 留空，note 写「文件未写」：
    guideline_title：开示文件里写的指南名
    period_start：开示期间的起点，写成 YYYY-MM-DD（文件只写到年或月就照写 YYYY 或 YYYY-MM）
    period_end：开示期间的终点，写法同上
    by_year：开示内容是否按年分开写（是 / 否）
    item_lecture_definition：文件里对应「講演料」的开示项目的原文名称、编号和金额基准
    item_manuscript_definition：文件里对应「原稿料」的开示项目的原文名称、编号和金额基准
    individual_disclosure：开示文件是否按个人逐一开示（是 / 否）
    covered_roles：开示覆盖哪些委员会或角色（例如「改訂委員会委員、外部評価委員」或「全委员」），以文件自己的写法为准
    listing_rule：开示文件是否只列出有开示内容的委员（是 = 没有开示内容的人不列；否 = 没有开示内容的人也列出、写「該当なし」等；不明）
    not_submitted_marker：文件里表示「某人某年未提交申报」的写法（例如脚注「※2021年分は未提出」）
  不同人或不同委员会的开示期间写得不一样时，每种期间各写一组 period_start、period_end，在 note 写明适用的委员会或角色。
  covered_roles、listing_rule 只按文件明写的内容填；文件没写的写「不明」，不要从名单的样子去推断。

【表 2：申报】写到 {{OUT_DECL}}
  只抽两个项目，以开示文件自己的项目定义为准，不要只看编号：
    講演料 = 会议出席（发表）、讲演等所支付的日当、讲演费那一项（常见写法「講演料」「講演料など」「日当」；日本医学会基准里是 (4)）
    原稿料 = 小册子、文章等的执笔所支付的稿费那一项（常见写法「原稿料」「原稿執筆料」；日本医学会基准里是 (5)）
  其他项目（役員・顧問、株、特許、研究費、奨学寄附金、寄附講座、旅費・贈答品、その他の報酬等）一律不抽。
  一行 = 一名委员 × 一家企业 × 一个项目 × 一个年份。
  列（UTF-8 带 BOM）：
    name：委员姓名，照开示文件原文
    affiliation：开示文件里该委员的所属，照原文；没有就留空
    company：企业或团体名，照原文抄写，不要改写、不要补全、不要翻译；表里只写编号的，按文件里的编号对照表换成企业名，并在 note 写明编号
    item：講演料 或 原稿料
    year：开示文件按年分开写的，填该年（如 2019）；不分年的，填开示期间的年份范围（如「2019-2021」）
    year_basis：表头写明年份 / 按同文件其他表推定 / 不分年 / 年份不明
    source_file：开示文件名
    source_location：「p.N」或「L0123」；表格写到第几个表（如「L0412 [table 7]」）
    source_text：原文中对应这一条的片段，照抄，80 字以内
    note：拿不准的地方（例如版面错乱、企业名断行、项目归属不清、列举以「、」结尾可能有缺）；没有就留空
  同一委员同一项目列了多家企业，就拆成多行。同一委员、企业、项目、年份重复出现只写一行。
  委员写「該当なし」或这两个项目为空的，申报表里不写行（名单里要有这个人）。
  表头没有写年份、但内容按列分年的表：
    - 同一文件里结构相同（列数和列的排法相同）的其他表写明了年份顺序时，按那个顺序填年份，year_basis 写「按同文件其他表推定」，note 写所依据的表的位置；
    - 找不到这样的表时，year 填开示期间的年份范围，year_basis 写「年份不明」，note 写明原因。
